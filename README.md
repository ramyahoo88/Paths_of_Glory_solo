# Paths of Glory Solo

Unofficial solo-play material for GMT Games' **Paths of Glory** (Deluxe edition). You need the physical game.

## General Staff — card-driven solo bot (branch `claude-bot`)

**General Staff** is a card-driven opponent for **either side** across the **full campaign**. It plays by the same rules you do, using a real hand of strategy cards, an 18-card Staff deck and printed priorities. It is a playtest draft, tested in about 22,000 simulated campaigns on a full rules engine.
